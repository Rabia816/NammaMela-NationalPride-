# 🌸 Namma Mela – Event & Cultural Management Platform

**Namma Mela** is a modern Android application designed to simplify the discovery, booking, and management of local cultural events, exhibitions, workshops, and community programs.

It bridges the gap between users and nearby cultural activities by providing a smooth digital platform powered by **Firebase** and modern Android technologies. Users can explore events, register easily, and manage their bookings in one place.

---

## ✨ Features

### 🎭 Event Discovery
- Browse cultural events and programs
- Category-based filtering system
- Clean and modern UI experience
- Search functionality for quick access

### 🔐 User Authentication
- Secure login and signup system
- Firebase Authentication integration
- Personalized user profiles

### 🎟️ Event Booking System
- Book seats for events instantly
- View booking history
- Real-time registration updates

### 🔔 Notifications
- Event reminders and updates
- Important announcements from organizers

### 💾 Offline Support
- Local caching using Room Database
- Smooth offline access to saved data

### 🖼️ Media & Gallery
- Event posters and promotional images
- Rich visual event previews

### 🧑‍💼 Organizer Features
- Create and manage events
- Update event details
- Track user registrations

## 🚨 Problem Statement

Many local cultural events and exhibitions lack proper digital platforms for visibility and management.

Users often face:
- Difficulty discovering nearby events
- Manual booking processes
- Lack of timely updates
- No offline support

Organizers face:
- Difficulty promoting events
- Managing registrations manually
- Limited audience reach

---

## 🎯 Objectives

- Improve discovery of local cultural events  
- Digitize booking systems  
- Improve accessibility of community programs  
- Provide secure authentication  
- Build scalable Android architecture
